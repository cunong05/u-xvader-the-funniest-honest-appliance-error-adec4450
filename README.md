Entry for the [make.fun](https://make.fun/c/u-xvader-the-funniest-honest-appliance-error-adec4450) competition **"The Funniest Honest Appliance Error"** — one line, at most 200 characters: the funniest honest error message an appliance could show.

## Entry

> Error 404: Ice not found. The freezer has been lying to you for weeks — everything inside is now soup.

102 characters, one line. The freezer reports the truth in its own flat voice: it has not been keeping anything frozen, and the owner is only finding out now that dinner has melted.

## How it works

`main.py` writes the entry to `/output/entry.txt` (and prints it), after validating the gate: UTF-8 text, 1–200 characters, a single non-blank line.

```sh
python3 main.py
cat /output/entry.txt
```
